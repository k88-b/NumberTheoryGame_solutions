# Number Theory Game Solutions

This repository contains a complete set of working solutions for the **Number Theory Game**.

These proofs are designed to successfully complete every level in the game. While they get the job done, they are not necessarily the most optimized or elegant approaches. If you find a shorter or better way to solve a level, contributions are highly welcome—please feel free to open a Pull Request!
